📦 SeriesPredictor

Este pacote fornece uma interface gráfica interativa (Shiny) para análise e predição de séries temporais, incluindo importação de dados,
    transformação para objetos ts, ajuste de modelos (por exemplo, ARIMA/SARIMA),  diagnóstico e geração de previsões e gráficos.

🚀 Instalação

Instalar diretamente do GitHub:
```r
install.packages("devtools")
devtools::install_github("andersoncsoliveira/SeriesPredictor")
```

▶️ Executar o aplicativo Shiny
```r
library(SeriesPredictor)
run_app()
```
